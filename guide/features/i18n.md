# 国际化 i18n

项目使用 **vue-i18n v11** 实现多语言支持，目前内置中文简体（`zh-CN`）和英文（`en-US`）两套语言包，覆盖 300+ 翻译键值。语言选择持久化到 localStorage，刷新页面后自动恢复。

## 技术架构

```
src/locales/
├── index.ts          # createI18n 实例创建，读取 localStorage 恢复语言
└── lang/
    ├── zh-CN.ts      # 中文简体（主语言，所有模块全覆盖）
    └── en-US.ts      # English（结构与 zh-CN 完全对应）
```

**核心配置：**

```ts
// src/locales/index.ts
const i18n = createI18n({
  legacy: false,                                          // Composition API 模式
  locale: localStorageCacheStorage.getItem('locale') || 'zh-CN',  // 读取持久化语言
  fallbackLocale: 'zh-CN',                               // 缺失翻译时回退中文
  messages: { 'zh-CN': zhCN, 'en-US': enUS },
})
```

## 快速切换

### 通过 Header 图标切换

顶栏的语言图标点击后即切换，无需刷新页面。

### 通过代码切换

```ts
import { useLocale } from '~/composables/web/useLocale'

const { locale, setLocale } = useLocale()

// 切换英文
setLocale('en-US')

// 切换中文
setLocale('zh-CN')

// 读取当前语言
console.log(locale.value)  // 'zh-CN' | 'en-US'
```

**`setLocale` 内部逻辑：**

```ts
function setLocale(lang: LocaleType) {
  locale.value = lang                              // 更新 vue-i18n 实例
  localStorageCacheStorage.setItem('locale', lang) // 持久化到 localStorage
  document.documentElement.lang = lang            // 更新 <html lang> 属性
}
```

### 通过 AppStore 切换

AppStore 中的 `locale` 字段与设置抽屉联动：

```ts
import { useAppStore } from '~/stores/modules/app'

const appStore = useAppStore()
appStore.updateSetting({ locale: 'en-US' })
```

## 在组件中使用

### 模板中使用 `$t()`

```vue
<template>
  <a-button>{{ $t('common.confirm') }}</a-button>
  <a-button danger>{{ $t('common.delete') }}</a-button>
  <p>{{ $t('common.total', { count: 100 }) }}</p>
</template>
```

### Script 中使用 `t()`

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n({ useScope: 'global' })

// 静态翻译
const confirmText = t('common.confirm')

// 带插值
const totalText = t('common.total', { count: pagination.total })

// 动态键名
function getStatusText(status: number) {
  return status === 1 ? t('user.statusNormal') : t('user.statusDisabled')
}
</script>
```

## 语言包结构

语言包按业务模块拆分，每个模块对应一个键名前缀：

| 模块前缀 | 说明 | 键值数量 |
|---------|------|---------|
| `common` | 通用文案（确认、取消、保存、删除等） | ~40 |
| `login` | 登录页（用户名、密码、登录按钮等） | ~15 |
| `menu` | 侧边栏菜单名称 | ~20 |
| `user` | 用户管理 | ~20 |
| `role` | 角色管理 | ~15 |
| `dict` | 字典管理 | ~15 |
| `menuManage` | 菜单管理 | ~15 |
| `log` | 操作日志 | ~25 |
| `online` | 在线用户 | ~25 |
| `notice` | 消息通知 | ~30 |
| `settings` | 系统设置 | ~10 |
| `header` | 顶栏工具（通知、全屏、退出等） | ~15 |
| `pagination` | 分页组件 | ~5 |
| `table` | 表格组件 | ~5 |
| `validation` | 表单校验提示 | ~10 |
| `error` | 错误页面（403/404/503） | ~10 |

### 键名示例

```ts
// common 通用
t('common.confirm')       // → 确认
t('common.cancel')        // → 取消
t('common.total', { count: 88 })   // → 共 88 条
t('common.selected', { count: 3 }) // → 已选 3 项
t('common.pleaseInput', { field: '用户名' }) // → 请输入用户名

// user 用户管理
t('user.addUser')         // → 新增用户
t('user.editUser')        // → 编辑用户
t('user.deleteConfirm', { name: '张三' }) // → 确定要删除用户「张三」吗？
t('user.genderMale')      // → 男
t('user.statusNormal')    // → 正常

// log 操作日志
t('log.typeLogin')        // → 登录
t('log.typeAdd')          // → 新增
t('log.success')          // → 成功

// error 错误页面
t('error.code403Title')   // → 无权访问
t('error.code404Desc')    // → 抱歉，您访问的页面不存在
```

## 插值语法

vue-i18n 支持命名插值，在翻译文本中用 `{变量名}` 占位：

```ts
// zh-CN.ts 定义
deleteConfirm: '确定要删除用户「{name}」吗？'
total: '共 {count} 条'

// 使用时传入插值对象
t('user.deleteConfirm', { name: record.username })
// 输出：确定要删除用户「张三」吗？

t('common.total', { count: 1024 })
// 输出：共 1024 条
```

## 类型安全

项目使用 TypeScript，但当前未开启 vue-i18n 的严格类型模式，键名以字符串形式使用。若需要更严格的类型检查，可通过以下方式开启（仅供参考）：

```ts
// 声明 vue-i18n 类型扩展（types/i18n.d.ts）
import zhCN from '~/locales/lang/zh-CN'

type MessageSchema = typeof zhCN

declare module 'vue-i18n' {
  export interface DefineLocaleMessage extends MessageSchema {}
}
```

## 语言持久化机制

```
用户选择语言
    │
    ▼
setLocale(lang)
    ├─ i18n.global.locale.value = lang   → 更新 vue-i18n，触发全局响应式更新
    ├─ localStorage.setItem('locale', lang) → 持久化（通过 localStorageCacheStorage）
    └─ document.documentElement.lang = lang → 更新 HTML lang 属性（SEO + 辅助技术）
    │
    ▼
页面刷新
    │
    ▼
createI18n({
  locale: localStorage.getItem('locale') || 'zh-CN'  // 自动恢复
})
```

## 注意事项

::: tip 所有用户可见文本必须走 `$t()`
界面中所有展示给用户的文字都应使用 `$t()` 包裹，包括：表格列标题、表单标签、按钮文字、弹窗标题、提示消息等。硬编码中文文本将在英文模式下无法切换。
:::

::: warning 中英文语言包必须同步
每次在 `zh-CN.ts` 中新增键值，必须同步在 `en-US.ts` 中添加对应的英文翻译。缺失的键名在英文模式下会自动回退到中文（`fallbackLocale: 'zh-CN'`），但这是最后兜底手段，不应依赖。
:::
